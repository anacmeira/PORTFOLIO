# Meu Portfólio Pessoal - Capacitação Byron Solutions

Este projeto foi desenvolvido como parte das entregas semanais da capacitação para a **byron Solutions**. Trata-se de um portfólio pessoal responsivo, criado do zero, com o objetivo de consolidar meus conhecimentos em desenvolvimento web front-end.

---

## Sobre o Projeto
O objetivo principal foi criar uma interface moderna, limpa e funcional para apresentar quem eu sou, meus projetos e minhas habilidades. 

Como sou apaixonada por **astronomia** e curso **Engenharia de Controle e Automação**, escolhi uma identidade visual inspirada no espaço profund, utilizando uma paleta com tons escuros, e além de um degradê entre roxo escuro e um azul profundo visando remeter a estética escolhida.

## Tecnologias e Conceitos Utilizados
* **HTML5:** Estruturação semântica da página.
* **CSS3 Avançado:**
    * **Variáveis CSS (`:root`):** Utilizadas para criar uma paleta de cores consistente e de fácil manutenção.
    * **Flexbox Layout:** Para alinhamento, espaçamento e distribuição dos elementos na tela sem quebrar o design.
    * **Media Queries (Design Responsivo):** Garantindo que o site se adapte perfeitamente tanto em celulares quanto em telas grandes (Desktop).
